## A. Scientific consistency

- [ ] Research Problem, RQ, H1 and Conclusions agree.
- [ ] All numeric claims match the final CSV and figures.
- [ ] Literature review and citations are independently checked in Mendeley.
- [ ] The manuscript has no unfinished placeholders.

## B. Reproducibility

- [ ] Protocol, configuration, code, requirements and seeds are included.
- [ ] Data or legally distributable acquisition instructions are included.
- [ ] Raw and summarized results, graphs and Reproducibility Report are present.
- [ ] A SHA-256 artifact manifest contains correct hashes for all packaged files.
- [ ] README explains the exact reproduction sequence.

## C. Rights and responsible release

- [ ] Authorship and affiliations reflect actual contributions.
- [ ] Licenses for text, code, data and third-party assets are compatible.
- [ ] No sensitive data, secrets or unauthorized third-party files are present.
- [ ] The policy of the intended journal / conference is checked if relevant.

## D. Review and Zenodo

- [ ] Supervisor's full scientific review has been received and documented.
- [ ] Comments have been resolved; supervisor has approved release.
- [ ] Zenodo draft metadata matches the approved manuscript.
- [ ] Community curation rules and submission workflow have been followed.
- [ ] DOI fields filled ONLY after actual reservation/registration.
