# AI Research Practices

**Відкритий освітньо-дослідницький проєкт для магістрантів спеціальності F3 «Штучний інтелект».**

Проєкт пропонує послідовну методику роботи над власним дослідженням: від постановки наукової проблеми й формулювання гіпотези до контрольованого експерименту, відтворюваних результатів, наукового рукопису та підготовленого Research Release.

> **Статус:** незалежні методичні матеріали рекомендаційного характеру. Проєкт не є нормативним документом університету та не представляє офіційного схвалення згаданими професійними організаціями.

## Дві практики — одна дослідницька траєкторія

| Етап | Зміст | Матеріали |
|---|---|---|
| **Науково-дослідна практика** | 7 спринтів: проблема, література, протокол, реалізація, експеримент, інтерпретація, наукова комунікація | [01-research-practice](01-research-practice/README.md) |
| **Переддипломна практика** | Подальша перевірка й розвиток дослідження, удосконалення рукопису та наукового продукту | [02-pre-diploma-practice](02-pre-diploma-practice/README.md) |

Наскрізна логіка: **проблема → контрольоване дослідження → відтворюваний результат → наукова комунікація → розвиток наукового продукту → інновації (за наявності підстав)**.

## З чого почати

1. Прочитати [загальні положення](general-provisions.md) та [політику рецензування й публікації](REVIEW_AND_PUBLICATION_POLICY.md).
2. Перейти до [семи спринтів науково-дослідної практики](01-research-practice/README.md).
3. Обрати та обґрунтувати власну тему **разом із науковим керівником**. Навчальний приклад у спринтах не є каталогом тем і не замінює індивідуальне дослідження.
4. Створити персональний **fork** цього репозиторію; працювати з матеріалами і власними артефактами у своєму fork.
5. Для кожного спринту використовувати `.ipynb` як основний виконуваний матеріал, `.md` — як версію для читання на GitHub; шаблони розташовані в каталозі відповідного спринту.

**Важливо:** у вихідному репозиторії (`upstream`) розміщуються навчальні матеріали. Результати індивідуальних досліджень студентів зберігаються в їхніх власних forks або інших дозволених сховищах, а не збираються в upstream. Публічне розміщення матеріалів можливе лише за належних прав і без розголошення конфіденційних даних.

## Наукова доброчесність і публікація

Результат не обов'язково має підтверджувати гіпотезу. Значення мають прозорий протокол, реальні вимірювання, обґрунтована інтерпретація та документовані обмеження. 

Оприлюднення студентського Research Release у відповідній Zenodo Community можливе **лише після остаточної позитивної рецензії наукового керівника**. Подробиці — у [Review and Publication Policy](REVIEW_AND_PUBLICATION_POLICY.md). DOI не є ознакою наукового рецензування або підтвердження авторських прав.

**Вихідний репозиторій є керованим власником джерелом навчальних матеріалів.** Студенти працюють у власних forks і синхронізують їх з upstream. Подача Issues та Pull Requests до вихідного репозиторію вимкнена; студентські результати не завантажуються в upstream.

**Зауваження, пропозиції та повідомлення про помилки в навчальних матеріалах** надсилаємо електронною поштою на **адресу для зворотного зв’язку**, зазначену в [`general-provisions.md`](general-provisions.md). GitHub Issues та Pull Requests для цього не використовуємо.
